DORMER LOFT PROJECT — GITHUB UPLOAD

1. Open your website repository on GitHub.
2. Open the folder named "images".
3. Upload the complete "dormer-loft" folder from this package.
4. Open your main HTML file, normally index.html.
5. Copy the code from "dormer-project.html" and paste it where you want the project to appear.
6. Open your main CSS file, normally style.css or styles.css.
7. Copy the code from "dormer-project.css" and paste it at the bottom.
8. Click "Commit changes".
9. Wait one or two minutes, then refresh your website.
